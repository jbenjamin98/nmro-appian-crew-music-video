# NMRO Appian Crew – Music Video

A flat-2D, 80s-hair-band-style animated music video for the "NMRO Appian Crew" song, built as a self-contained HTML/SVG player.

Open `video/index.html` (or the GitHub Pages site) and click to play.
Controls: Space = play/pause, ←/→ = ±5 s, `[` `]` = nudge lyric sync, F = fullscreen.

- `video/characters.js` – SVG character renderer
- `video/scenes.js` – backgrounds and props
- `video/timeline.js` – lyrics, timing and scene/cast layout
